# Secret de Maison — независимый демонстрационный прототип

[Открыть GitHub Pages](https://gkkm8bm7rn-eng.github.io/Test/)

Проект для обсуждения коммерческого маркетинга и развития мебельного e-commerce. Не официальный магазин Secret de Maison: нет оформления заказа, оплаты, CRM, обещаний наличия или доставки. Все суммы **демонстрационные**, для проверки расчёта корзины, а не публичные розничные предложения.

## Возможности

- 01 — петроль / терракота по умолчанию; 02 — олива / бордо. Сознательный выбор сохраняется. Автосохранённая старая олива мигрирует на новый основной вариант; корзина сохраняется, в том числе позиции прежней версии.
- 20 моделей, официальные артикулы, локальные WebP и содержательные галереи. [Источники и особенности проверки](SOURCES.md), [машиночитаемый манифест](assets/products/manifest.json).
- Категории → подкатегории → каталог → товар. Плашки на товарах, хлебные крошки, история браузера и возврат к фильтрам/позиции.
- Пересечение категории, подкатегории, материала и редакционной подборки; сортировка и сброс. Подборки не выдаются за коллекции бренда.
- Галерея: стрелки, миниатюры, клавиши в области фото, горизонтальный свайп; без автопрокрутки и фиктивных переключателей для одного фото.
- Светлые адаптивные карточки с общими строками для фотографий, плашек, названий, цен, артикулов и кнопок. Текст показывается целиком; узкие экраны и крупный шрифт уменьшают число колонок. Для браузеров без subgrid предусмотрено выравнивание по фактическим размерам текста.
- Добавление в корзину прямо из каталога, подборок и главной. После добавления карточка показывает количество: +/− и ручной ввод, синхронные с корзиной. Уменьшение до нуля возвращает кнопку «В корзину».
- Демо-корзина: ручной ввод, +/−, удаление, пересчёт строк, суммы и бейджа; сохранение в localStorage.

## Локальный запуск и проверки

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000/`. Прямые ссылки используют hash и работают при перезагрузке на GitHub Pages, например `/#/catalog` и `/#/product?id=25271`.

```sh
npm ci
node --check products.js
node --check app.js
python3 scripts/check_site.py
node scripts/smoke_dom.cjs
npx playwright install --with-deps chromium firefox webkit
node scripts/browser_test.cjs --base-url http://127.0.0.1:8000/ --screenshots
npm run test:cards -- --base-url http://127.0.0.1:8000/ --screenshots
npm run test:layout -- --base-url http://127.0.0.1:8000/ --screenshots
```

Проверка опубликованной версии тем же сценарием:

```sh
node scripts/browser_test.cjs --base-url https://gkkm8bm7rn-eng.github.io/Test/ --screenshots
npm run test:cards -- --base-url https://gkkm8bm7rn-eng.github.io/Test/ --screenshots
npm run test:layout -- --base-url https://gkkm8bm7rn-eng.github.io/Test/ --screenshots
```

Итоги фактически выполненного QA — в [QA_REPORT.md](QA_REPORT.md). Скриншоты/JSON браузерных прогонов доступны также в artifacts GitHub Actions. Эмуляция браузера не заменяет проверку на физическом iPhone или Android.

## Публикация и откат

Существующий GitHub Pages: `main`, корень `/`, Deploy from a branch. Хостинг не переносится. Проверки — `.github/workflows/validate-site.yml`. Перед публикацией обязательны локальные проверки; после публикации — успешный Pages deployment и повторный browser QA настоящего HTTPS URL.

Исходное состояние: `446a5c128ec10ce481ac05edfc5857e0706e9855`, резервная ветка `backup/pre-20261026`. Исходные фотографии сохранены; новые лежат в `assets/products/verified/`. Для отката использовать отдельный `git revert` выпускного коммита, без переписывания истории.
