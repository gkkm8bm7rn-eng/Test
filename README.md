# Secret Maison — Test

Независимый **демонстрационный прототип** предложения по развитию сайта Secret de Maison. Неофициальный проект; действующий сайт и его данные не изменены.

## Что посмотреть

Откройте `index.html` через работающий веб-сервер или GitHub Pages (не через встроенный просмотрщик HTML-файлов iPhone). В демо доступны:

- три варианта оформления: **олива + бордо**, **петроль + терракота** и **графит / глубокий петроль + коньяк**;
- главная, каталог, коллекции, карточка товара, журнал, корзина, экран «Идея»;
- фильтрация по категориям, коллекциям и материалам; сортировка;
- корректный демонстрационный пересчёт количества/суммы в корзине при ручном вводе;
- адаптивные экраны для телефона и компьютера.

**Важное ограничение:** это дизайн- и UX-концепт. Фото из внешних источников могут не загрузиться или не совпасть с нужным исполнением; при отсутствии проверенного изображения предусмотрен явный маркер сверки, а не подмена другим товаром. Демонстрационные цены, наличие и атрибуты перед показом необходимо сверить с действующим ассортиментом. Оплаты, заказа и интеграции с продавцом здесь нет.

## Открыть с телефона через GitHub Pages

В репозитории GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → Branch: main / (root) → Save**. После активации GitHub покажет адрес «Visit site». Открывайте его в Safari — кнопки будут работать как на обычном сайте. Это отдельная публичная демонстрация, не официальный ресурс компании.

Исходный сайт бренда: https://secretdemaison.ru/
